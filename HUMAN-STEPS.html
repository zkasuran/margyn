Shipped today: margyn.xyz is live. It is Tiun-native from the first commit.

Margyn audits the machinery that is supposed to catch your bugs. Not your code. It finds tests that assert nothing, files your repo reads that git never committed, gates no workflow invokes, plus linter exclusions hiding in .gitignore. Every finding ships a reproduction you can run. No reproduction, no finding.

Tiun carries auth, checkout and the customer record. The interesting part was the licence: the scanner is a local CLI, so it cannot call home to check entitlement. A CI runner on a private network would fail. A licence check that needs the network is a new way for a build to go red for a reason that is not about the code. So the server mints an Ed25519 licence from what Tiun says the user bought, then the CLI verifies it offline against a public key compiled in. Billing never fails your build: no licence prints why, then the free scan runs in full.

We ran it on ourselves. At the default cap of four mutations, three of our own tests turned out to be watching nothing. One of those was inside the mutation checker itself. That number is on the site rather than hidden.
